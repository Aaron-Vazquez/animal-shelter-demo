# Animal Shelter Demo

Proyecto ficticio para practicar Git.

El repositorio simula un pequeño registro de animales de un refugio.
La idea es usar archivos fáciles de entender para practicar:

- commits
- branches
- merge
- conflictos
- diff
- stash
- revert
- rebase
- historial

## Estructura

- `data/animals.csv`: animales registrados
- `src/summary.py`: pequeño script de resumen
- `docs/notes.md`: notas del proyecto
